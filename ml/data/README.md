# ml/data: local only

Put the DGamesDataSet CSV and feature dictionary here on your own machine. Everything in this folder
except this README is git-ignored.

- The source dataset's consent covered the original research, not our use. Do not redistribute it.
- Local session telemetry is children's personal (and partly health) data under Act 843. It must
  never be committed. See [spec C3](../../spec/02-architecture.md#c3-data).
